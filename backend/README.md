# Backend — Personal Expense Tracker

Phần Backend xây dựng theo kiến trúc **Monolithic Layered Architecture + Package-by-Feature** sử dụng **Spring Boot 3** và **Java 17/21**.

## Tech Stack
* Java 17 / 21
* Spring Boot 3.x
* Spring Data JPA
* Spring Security & JWT (Stateless)
* Jakarta Bean Validation
* PostgreSQL Driver
* Lombok
* JUnit 5 & Mockito
