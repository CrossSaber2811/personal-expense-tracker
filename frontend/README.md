# Frontend — Personal Expense Tracker

Phần Frontend xây dựng theo cấu trúc **Feature-based Structure** sử dụng **React**, **TypeScript**, và **Vite**.

## Tech Stack
* React 18+
* TypeScript
* Vite
* React Router DOM
* Axios (Interceptor tự đính kèm JWT)
* Lucide React / Tailwind CSS or Vanilla CSS for UI
* Chart.js / Recharts (vẽ biểu đồ chi tiêu và xu hướng dòng tiền)
